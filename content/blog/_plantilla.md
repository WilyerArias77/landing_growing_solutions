Este archivo es la PLANTILLA: empieza por "_" y nunca se publica.

Para publicar un artículo:

1. Copia este archivo con un nombre en minúsculas y guiones, por ejemplo `cierre-contable-mensual.md`. Ese nombre es la URL: /blog/cierre-contable-mensual
2. Llena el encabezado de arriba y pon `borrador: false` cuando esté listo.
3. Haz commit. La GitHub Action genera las páginas y Vercel las publica.

## Formato que se puede usar

- Títulos con `##` y `###`
- Listas con guion o numeradas
- **Negrita**, *cursiva* y enlaces como [la página de contabilidad](/servicios/contabilidad)
- Citas con `>`

No se admite HTML: se muestra como texto.
